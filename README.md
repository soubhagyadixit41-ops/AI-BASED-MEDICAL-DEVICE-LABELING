
# LabelGuard AI

AI-based medical device labeling automation prototype.

## Features
- Smart Change Impact Analysis
- Compliance Risk Checker
- RAG-based reference retrieval and label draft preview
- Computer Vision artwork difference detection
- Streamlit dashboard

## Tech Stack
Python, Streamlit, Pandas, Sentence Transformers, FAISS, OpenCV

## Run Locally
Install dependencies:

    python -m pip install -r requirements.txt

Start the dashboard:

    python -m streamlit run app.py

## Disclaimer
This prototype uses fictional demonstration data. It does not provide
regulatory approval or establish medical-device compliance.
The current draft generation is template-based, and artwork validation
demonstrates pixel-level difference detection.
